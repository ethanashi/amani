# certificate

Apache-2.0; copyright 2026 Ethan Ashihundu.

Public bundle manifest and package-certificate types, canonical JSON and digest/path primitives. No engine dependency. The canonical encoding is an explicitly relicensed copy of the owner-authored encoding in bio-core.

The root lint checks this package boundary; tests use synthetic data.

Ships native JavaScript and TypeScript declarations; no build step or engine is required.
